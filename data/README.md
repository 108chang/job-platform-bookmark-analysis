# 데이터 출처와 공개 범위

코드잇 스프린트 데이터 분석가 16기 Part 2 중급 1 팀 프로젝트에서 제공된 채용 플랫폼 데이터입니다. 사용자가 제공한 `subscription_dump.sql`은 MySQL 8.0 형식이며 크기는 2,386,521,919바이트(약 2.39GB)입니다. 공개 데이터 다운로드 링크와 재배포 허용 범위는 제공 자료에서 확인되지 않았습니다.

원본에는 사용자 식별자, 지원·북마크 기록과 행동 로그가 포함됩니다. 공개 재배포 범위가 확인되지 않은 개별 기록과 대용량 덤프는 저장소에 포함하지 않습니다. 분석용 CSV와 개인별 로그도 공개하지 않으며 `.gitignore`로 제외합니다.

주요 분석 테이블은 `Job`, `Application`, `JobBookmark`, `Company`, `CompanyFund`, `Log_2022`, `Log_2023`입니다. 사용자와 공고의 연결 키는 `user_uuid`, `job_uuid`입니다. 원본 CREATE TABLE 정의만 추출한 [schema.sql](../sql/schema.sql)을 구조 참고 자료로 제공합니다. 실제 행 데이터는 포함하지 않습니다.

분석 기간은 2022-01-01 이상, 2024-01-01 미만(KST)입니다. 원본 전체 테이블 크기와 보고서의 분석 대상 건수는 구분해야 합니다. 노트북에 필요한 가공 파일 목록과 실행 제약은 [실행 안내](../notebooks/README.md)를 참고하세요.
